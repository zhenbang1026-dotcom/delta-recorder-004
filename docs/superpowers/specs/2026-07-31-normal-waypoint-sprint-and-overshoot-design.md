# 普通路线点连续疾跑与越过点可选跳过设计

## 背景与根因

路线 `routes/主变电站右1出生点到井盖.jsonl` 在 TEXT 角度模式下回放时，会在固定的普通中继点附近出现短暂慢走或走停。

日志 `logs/寻路诊断/20260731_164022/steps.jsonl` 表明：普通点发生大角度转向后，执行器会释放 `W/Shift`；距离目标还剩 6～10 像素时，动作策略原本已选择“疾跑前进并微调”，但近点位保护又把它降级成“前进并微调”，导致只重新按下 `W`，没有重新触发疾跑。人物越过普通点时，现有逻辑也不会识别“已越过”，而是将人物转回当前点，进一步造成走停。

## 目标

1. 增加“普通点转弯保持疾跑”复选框，默认开启并持久化。
2. 开启该选项后，普通路线中小角度近点微调不再取消已经由动作策略选定的疾跑。
3. 增加“越过普通点自动跳过”复选框，默认关闭并持久化。
4. 开启跳过选项后，只跳过明确已经越过的普通自动中继点。
5. 精准点、动作点、首点和终点仍必须按原逻辑到达，不能被跳过。
6. 不增加前瞻寻路，不修改路线文件，不改变到点阈值、精准点补正和大角度原地转向。

## 方案

### 1. 可选的普通点转弯疾跑

主界面增加“普通点转弯保持疾跑”复选框，默认勾选。设置保存键为 `普通点转弯保持疾跑`，只接受布尔值；旧设置缺少该字段或字段无效时使用 `True`。

开关值从 `主界面.start_cruise()` 传给 `巡航()`，再传给 `巡航控制器`。在 `巡航控制器._处理近点位转向()` 中继续保留现有近点位角度限幅：

- 选项开启时，原动作是“疾跑前进”或“疾跑前进并微调”，输出“疾跑前进并微调”。
- 选项关闭时，近点位微调继续输出“前进并微调”，保持旧的慢走转弯行为。
- 两种模式下，原动作是普通前进类动作时，都输出“前进并微调”。
- 两种模式下，原动作是“转向”时都保持现状，继续原地调整并释放移动键。

普通模式的大角度阈值保持现有策略：TEXT 模式约为 32 度。达到大角度阈值且距离足够时，无论复选框是否开启，都停车原地转向。该选项只控制中小角度近点微调是否保留疾跑，不强制所有场景全程疾跑。

### 2. 可选的普通点越过检测

主界面增加“越过普通点自动跳过”复选框，默认不勾选。设置保存键为 `越过普通点自动跳过`，只接受布尔值；旧设置缺少该字段或字段无效时使用 `False`。它与“普通点转弯保持疾跑”互相独立，可以组合成四种模式进行对比测试。

开关值从 `主界面.start_cruise()` 传给 `巡航()`，再传给 `巡航控制器`。关闭时不运行越过判定，保持旧路线现有行为。

开启时，当前点必须同时符合以下条件才能跳过：

- 不是首点，也不是最后一个点；
- 是自动路线点；
- 不是精准点；
- 没有路线动作；
- 当前距离大于到点阈值；
- 人物位置已经越过“上一点 → 当前点”的前向平面；
- 下一点比当前点更接近人物。

越过平面使用点积判断：

```text
(人物位置 - 当前点) · (当前点 - 上一点) > 0
```

同时要求“到下一点的距离 < 到当前点的距离”，避免仅因横向偏移或急转弯误判。满足条件时只跳过当前点一次，下一次循环再重新读取坐标和角度，不连续批量跳点。

该判断只决定是否放弃一个已经错过的普通点，不提前把下一点作为转向目标，因此不属于前瞻寻路。

### 3. 日志与状态

跳过普通点时记录独立日志事件 `event=waypoint_skipped`，至少包含当前索引、人物坐标、被跳过目标、下一目标和两个距离。UI 控制诊断状态显示“已越过普通点，切换下一点”。

跳点沿用“自动路线切换下一个点”动作，不释放当前 `W/Shift` 状态。若下一点需要大角度转向，后续原有动作策略仍会正常停车转向。

## 不在本次范围内

- 不强制大角度转弯、精准点、动作点和终点一直按住疾跑。
- 不改变自动路线抽稀距离。
- 不提前朝下一点导航。
- 不修改精准点、动作点、首点、终点或路线 JSONL 格式。
- 不调整坐标识别、角度识别和 YOLO 代码。

## 测试与验证

1. 先新增失败测试：TEXT 模式下，距离 8、角差 20 度且开启转弯疾跑时，近点动作应保留“疾跑前进并微调”，当前代码应因返回普通前进而失败。
2. 验证关闭转弯疾跑时，同一输入仍输出“前进并微调”；验证超过大角度阈值时，两种模式都保持原地转向。
3. 验证普通前进类动作经过近点限幅后仍保持普通前进，不影响精准模式的慢速行为。
4. 验证转弯疾跑默认开启、越过跳过默认关闭；两个设置都能独立保存和恢复。
5. 验证越过开关关闭时不跳点，开启后明确越过且下一点更近的普通自动中继点会被跳过。
6. 验证首点、终点、精准点、动作点、非自动路线点和未明确越过的急转弯点不会跳过。
7. 验证 UI 启动回放时能独立透传两个选项的值。
8. 执行相关测试、完整 `pytest`、核心 Python 文件 `py_compile` 和 `git diff --check`。
9. 实机使用 `主变电站右1出生点到井盖.jsonl` 对比四种开关组合，确认转弯速度与越过点行为分别只受各自选项控制。
